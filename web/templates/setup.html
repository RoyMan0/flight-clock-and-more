API Keys

All optional, and all free: add keys to unlock specific features. Each link opens the sign-up page; make an account, copy the key and paste it here.

Free: 500 calls a day, plenty for the clock. The clock's current weather and forecast. Get a key (after signing up it's under Development → API Keys).
Free: 1,000 lookups a month. Where each overhead flight is going, and its delays. Get a key (it's on your account page after you sign up).
Free: about $5 of lookups a month ($10 if you share ADS-B data with FlightAware, e.g. PiAware), used when AirLabs runs out. It asks for a card, but the clock stops using it at $4.50 a month, so it stays free. Get a key (choose Personal, then API Keys).
Free: 1,000 calls a day. Rain-starting-soon and strong-wind alerts on the clock. Get a key, then subscribe it to One Call API 3.0 (it asks for a card; the first 1,000 calls a day are free, and you can set a daily limit of 1,000 so it never charges). A new key can take an hour to start working.
Running out of free flight lookups? The Pi can hold several AirLabs and FlightAware keys and switches to the next one when a key runs low — add extra keys later under Config → API & Metrics. Some people get more keys by signing up again with another email address, but AirLabs' terms allow one account per person and they may block keys that break this, so that's at your own risk. Free sources (FlightStats, adsbdb) are always tried first, and a smaller search radius or higher minimum altitude also means fewer lookups.
Keys are saved locally on the Pi and never sent anywhere else. You can update them anytime from the main web dashboard.
