About

How the display works and what everything means

LED Matrix Display

A Raspberry Pi drives a 64×32 pixel RGB LED panel that rotates through the modules you turn on — clock & weather, overhead flights, transit, world clock, now playing, sports, news and more. Each module fills the panel for the number of seconds you choose, then it moves to the next. When a plane flies overhead, the flight tracker can jump in and show it. Everything is managed from these web pages, on a laptop, tablet or phone.

The Tabs
Dashboard

The at-a-glance home page.

  • Live Preview — exactly what the panel is showing right now. A badge lights up when a plane is overhead.
  • Plugin Rotation — which module is on now and what's coming up. Tap one to show it immediately.
  • Overhead Now — planes currently nearby: airline, aircraft, route, distance and direction.
  • System — the Pi's CPU temperature, uptime and memory, plus buttons to check for and install updates, reconnect a Bluetooth speaker, restart the app, reboot or shut down.
Config

Where everything is set up. Two tabs:

  • Config:
    • Plugin Order & Duration — turn modules on or off, reorder them, and set how long each one shows.
    • System Settings — 12/24-hour clock, time zone, units, day and night brightness, quiet hours ("clock only"), clock alerts, and LED panel options.
    • WiFi & Bluetooth — join a network or pair a speaker.
    • A card for each module (stops, cities, teams, music sources…), most with a Test button that previews the result.
    • Backup & Restore for your settings.
  • API & Metrics — API keys for the flight and weather services, and how much of each service's free allowance you've used.

Click a card's Save to apply its changes. Most apply immediately; a few system settings restart the app automatically.

Display

A large live view of the panel, with remote control.

  • The preview is drawn LED by LED and sized to your screen.
  • Tap a module to pin it — it stays on the panel (even if a plane flies over) until you tap Return to Rotation. Handy for checking a module after changing its settings.
  • Modules that are turned off can still be pinned for a look; they're marked "(off)".
Flights

History of every plane the tracker has logged overhead.

  • Flight Statistics — daily average, busiest day, peak hour and peak day of the week. Charts show traffic by hour and day, top airlines, local vs flyover traffic, and aircraft types. The daily log at the bottom lists each day; click a date to see every flight from that day.
  • Closest Flights — the planes that passed nearest to you, with a map.
  • Farthest Routes — the longest-distance flights seen overhead, with a map.

The Modules
Clock & Weather
Clock

Displayed top-left. Color changes with the actual sunrise/sunset times for your location.

Orange — daytime (sunrise → sunset)
Blue — nighttime (sunset → sunrise)

Format is 12-hour or 24-hour, configurable on the Config page. When alerts are active the clock shifts to a smaller font to make room.

Temperature

Displayed top-right. The color encodes humidity, not temperature itself.

0% humidity — white
100% humidity — dark blue

Shows ERR in red if the weather API is unavailable.

Date & Moon Phase

The date (e.g., "Jun 04") is displayed top-right below the temperature. Its text gradient reflects the current moon phase.

Overhead Flights

Tracks the nearest aircraft flying overhead within a configurable radius (default 25 nm), filtered to altitudes between 8,000 and 100,000 ft. Up to 5 flights are tracked simultaneously and displayed in rotation. Updates every 60 seconds.

Journey View

Shows the flight's route context.

  • Origin & Destination — 3-letter IATA airport codes
  • Progress arrow — visual bar showing the aircraft's position between origin and destination
  • Distance — miles or km to each airport (configurable)
  • Flight number — airline callsign with numeric portion highlighted separately
Plane Details View

Shows the aircraft's technical details.

  • Aircraft type — ICAO designation (e.g., B787, A320)
  • Registration — tail number
  • Altitude — displayed as FL (flight level) at ≥ 18,000 ft (e.g., FL350); feet or meters below that
  • Ground speed — in knots

Radar Mode

Optional full-screen radar view showing all tracked aircraft overhead plotted on a map within the configured search radius.

Data sources: adsb.lol (primary), FlightRadar24, OpenSky Network (fallback). Route and schedule data from adsbdb, AirLabs, FlightStats, and FlightAware.

Stocks

A scrolling dual-row ticker. ETFs run along the top half; individual stocks run along the bottom half. Each block shows the ticker symbol, current price, and today's percentage change.

Color Coding
Green — price up today
Red — price down today
Grey — flat (0% change)

Price formatting: prices ≥ $100 show no decimal places (e.g., $123); prices < $100 show two decimals (e.g., $45.67).

Data sources: Charles Schwab API when brokerage credentials are configured; Yahoo Finance as a public fallback.

World Daylight Map

Renders the current day/night terminator line across a world map, updated in real time. The sun and moon are drawn at their actual positions on the globe. The moon icon reflects the current lunar phase — matching the phase shown on the clock screen's date gradient. No external API is required; all astronomy calculations run locally on the Pi.

Transit Arrivals/Departures

A station-style board showing the next trains or buses at the stops you choose, with columns for the line (Ln), destination (Dest) and minutes away (Min). Times count down live between refreshes. Pick as many stops as you like — each with its own line, station and direction.

Supported Agencies
Chicago CTA 'L' Trains Chicago CTA Buses Denver RTD (bus & rail) New York MTA Subway

Chicago needs free CTA Train Tracker / Bus Tracker API keys. Denver and New York need no key — the first time you pick one, its schedule data downloads in the background (the config page shows "preparing…").

Combined — the next three across all your stops, soonest first.

Scroll — the next three for each stop, scrolling up under the fixed Ln / Dest / Min header (like Breaking News), with a faint line between stops. Speed is adjustable.

World Clock

The current time in the cities you pick, four at a time — city on the left, time on the right, in the order you arrange them. With more than four cities the list scrolls up continuously, and a faint dashed line marks where it starts over. About 230 cities are available, covering every time zone (including half- and quarter-hour zones like India and Nepal). Times follow your 12hr/24hr setting and adjust for daylight saving automatically. No internet or API key needed.

Colours
Orange — the sun is up in that city
Blue — it's night there

Same colours as the main clock. Day or night is worked out from the sun's real position over each city, so it tracks actual sunrise and sunset.

+1 / -1 — that city is already on tomorrow's date, or still on yesterday's, compared with yours.

Now Playing

The song playing right now: the title scrolls across the top in green, the album artwork sits bottom-left, and the artist and album appear beside it (scrolling if they're long). A thin green bar along the bottom shows how far into the song you are. It shows during its turn in the rotation while music is playing and is skipped otherwise.

System Stats

Live health of this Pi and any other computers you add — a Mac, a NAS, a Linux server. Each machine shows its name — with its uptime (time since it last restarted, e.g. 12d 04h) on the right, if turned on — then one line per stat with a bar underneath. One machine with up to three stats (plus uptime) fits on one screen; with more machines or stats the list scrolls up continuously, with a faint dashed line between machines. Values refresh every few seconds.

Speeds use B, K, M and G (bytes, kilobytes, megabytes, gigabytes per second), averaged over each refresh so they don't jump around. The disk and network bars use a log scale, so a trickle and a big transfer both register: 1 KB/s is empty, and the bar is full at the speed you pick for that machine (up to NVMe-class disks and 25 Gb networking).

Red — hot (over 85°C / 185°F)

Shown in °F or °C to match your system units setting.

Machines
  • This Pi works out of the box.
  • Other computers are read over SSH with this Pi's own key; nothing is installed on them. Turn on SSH (Remote Login on a Mac; Terminal & SNMP on a TerraMaster), then run the one-line command from the config page once.
  • Linux machines (NAS boxes, servers, other Pis) report every stat. Macs report everything except temperatures, which macOS only shares with admin tools; install the free smctemp tool to add them.
  • A machine that can't be reached shows OFFLINE next to its name.
  • Turn machines on or off and change their order in the config page; each machine can show a different set of stats.
AI Usage

How much of your Claude and ChatGPT Codex subscription limits you've used. Each service gets its own page: a header with its logo, then Current (the rolling 5-hour session limit) and Weekly (the 7-day limit), each with a bar. The bottom line shows when each one resets: clock times (11:00PM · WED 8AM), countdowns (2h14m · 4d6h), both alternating every 3 seconds, or nothing, which gives the bars more room. Usage refreshes every 5 minutes.

Bar Colours
Green: under 50%
Yellow: 50–74%
Orange: 75–89%
Red: 90% and over
Setup
  • No API key or extra cost. The Pi reads the same usage numbers the official apps show, using a login you make on the Pi itself, so your computer's login isn't affected.
  • Claude: over SSH on the Pi, install Claude Code (curl -fsSL https://claude.ai/install.sh | bash), then run claude auth login and sign in. The long-lived claude setup-token does not work, because it isn't allowed to read usage.
  • ChatGPT Codex: install the Codex CLI (npm install -g @openai/codex), then run codex login --device-auth. Only Codex has usage limits that can be read. Regular ChatGPT chat doesn't show a usage meter.
  • The Pi keeps the login fresh on its own. If it ever shows LOGIN NEEDED, run the login command again.
  • Use the Test button on the config page to check each login and preview the board.
  • These usage feeds aren't official public APIs, so a change on Anthropic's or OpenAI's side could break them until the app is updated. The board keeps showing the last good numbers in the meantime.
